# subtui

A terminal UI for [Navidrome](https://www.navidrome.org/) / OpenSubsonic / Subsonic servers, built with [OpenTUI](https://opentui.com). Talks to the server through [subsonic-api](https://github.com/explodingcamera/subsonic-api).

## Requirements

- [Bun](https://bun.com)

## Setup

```bash
bun install
```

## Run

```bash
bun index.tsx
```
